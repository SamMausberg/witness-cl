# Claim ledger

| Claim | Evidence/status | Explicit limitation |
|---|---|---|
| Online finite-class learning from own binary feedback | Executed implementation and tests | Not general neural continual learning |
| Active witnesses reconstruct the full-history version set | Executed exhaustive/sampled tests and mathematical induction | Relative to the fixed declared class; not arbitrary semantic sufficiency |
| Truth retention and sound, persistent unanimous predictions | Conditional mathematical proofs; Lean source attempt | Requires realizability, exact feedback, stationarity, total deterministic programs, correct public routing |
| Other public scopes retain their stored contracts | Implementation tests and logical proof source | Does not certify an LLM router or learned latent scope identification |
| No offline retraining in the primary method | Architecture and code | Online elimination and auditing still consume computation |
| Fewer hypothesis evaluations than rebuilding from all history | Executed operation counts | Deliberately redundant symbolic control; not a serving/GPU speedup |
| Better novel-input accuracy than exact-input lookup | Executed synthetic experiment | Grammar is supplied to every inductive method; no LLM result |
| Hidden changes can produce wrong conditional certificates | Executed tests and measured negative controls | Quarantine detects after failure; does not prevent the first failure |
| Anytime candidate admission with global error budget | Standard supermartingale proof and exact-rational implementation | Probability theorem not Lean-checked; unique global indices, frozen snapshots and fresh valid paired rewards required |
| Audit sample costs can be large | Executed Monte Carlo diagnostic | Synthetic reward model; not a measured LLM effect size |
| Online weight update baseline | Recursive least squares tested against batch solution | Uses explicit labels and is not a neural/LoRA experiment |
| A model-facing runner exists | Mock-tested local HTTP client and synthetic runner | No actual LLM/server run; no performance claim |
| CL-Bench integration | Upstream interface inspected; integration plan written | No task adapter or official benchmark run delivered |
| Lean kernel verification | Not completed: `lake` absent, official download blocked | Source inspection is not formal verification |
| General benchmark superiority or universal no forgetting | Not established | Must not be claimed in a paper or repository description |

The archived raw episode CSVs, tests, and paper tables must remain linked. Never
replace an unexecuted experiment with a plausible number, or call a symbolic
control an implementation of Mem0, ACE, MemProbe, TTHE, or an LLM.
