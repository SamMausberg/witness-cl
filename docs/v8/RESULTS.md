Checked and unchecked fragment memory each admitted **zero executable relations**, made **zero USE/COMPOSE actions**, and therefore supplied **no observed abstraction transfer**. Every arm scored **0/8 before and after on the fresh old-task panel**. This is no demonstrated retained competence.

The actual run completed all **288 arm-episodes** in **690.126634 seconds** under the 1,800-second ceiling. Independent saved-data replay passes for every episode, with complete known usage, unchanged sources and no resource/runtime stops or protocol issues. ## What failed and what remains uncertain

No arm queried the documentation catalog in ordinary learning. The first full-history/stateless gross calculation sums a guessed physical amount column, observes 284,375, and returns that number. The actual target is 7,817.75 dollars and requires quantity/unit semantics. SQL executes correctly, but the proposed expression computes the wrong quantity. The first insight reflection describes failure feedback of zero as evidence that its zero answer was correct.

Different empty-memory prefixes coincide with different first actions. The same shared model/system prompt does not mean every complete input is identical. There was no causal prefix ablation, and the result does not isolate model capacity, quantization, greedy decoding, prompting, action-schema behavior or memory design. It applies to the frozen configuration. Greedy non-thinking decoding differs from the model card's recommended sampling; revised settings require a new development freeze.

The environment offers compositional opportunities but its target taxonomy does not show actual acquisition. Seven old targets change from warm data; refunded-order count stays 22 by construction. The convention/template split also requires disjoint numeric seeds for independent future fixtures. Only the reusable development condition ran. No model evaluation was performed on heldout, nonreuse or near-match streams. [Environment review](PILOT_ENVIRONMENT_REVIEW.md)

## What is implemented and proved

The agent can propose new parameterized SELECT relations from its own successful query prefix, execute a charged scalar reconstruction and store an immutable checked entry. Future actions support content-selected binding changes and composition with a new outer query. No task IDs, gold numerical targets, source evaluator recipes or enumerated semantic feature library are supplied. SQL syntax and the pretrained model remain inductive biases.

The new Lean layer proves exact typed prepared-request compilation, witnessed binding and CTE expansion properties. Its fallback/retention statement concerns a modeled answer-level operator under explicit premises; runtime rejection instead returns feedback, changes the prompt and consumes budget. It is not an unconditional retention theorem for the actual agent. Matching one observed scalar is finite evidence, and neither a constant answer nor an unused CTE counts as discovered transfer.
