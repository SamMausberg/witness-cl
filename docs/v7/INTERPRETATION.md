# What the v7 result changes

The preregistered transfer test passes: feature-bank reuse improves the two
shared novel reports by .12240 reward over the same bounded search without
reuse, with a nominal paired Student interval [.03158,.21321]. The first-eight
negative control is exactly zero in this sample. This is a measurable transfer
mechanism inside the supplied grammar and authentic report routing.

The larger practical claim fails decisively. At the common 4096-SELECT ceiling,
reuse scores .47437 final macro reward while each of the three fixed simple
controls scores 1.0. Its difference is -.52563, interval [-.55610,-.49517]. Sparse
full-history learning also beats reuse on the matched shared-novel metric.
The audited sparse control also reaches perfect final-panel accuracy, so this
experiment does not show that auditing alone causes failure. The failed practical
claim concerns this particular bounded growth, screening and audit combination.
We therefore do not treat the primary ablation win as a stateful benchmark win.

The budget result exposes an opportunity cost: reuse reaches about 138 ordinary
examples, versus 904 for audited sparse recovery and 1109 for the ungated controls.
A substantial amount of testing is spent on proposals selected from little
ordinary evidence. The admission test prevents those unproven changes, but its
fresh labels are excluded from fitting, so testing also delays useful learning.
The final panel scores every report, including any that might not have been
reached. In this actual sample every report is reached, but novel reports
usually receive only about 10--11 ordinary examples.

The budget table's `Shared first24` field averages the examples actually observed
with exposure index at most 24; its rows do not all contain 24 examples. It is a
censored-prefix descriptive score and should not be compared as the matched
complete-window transfer estimand. The budget hypothesis uses the fully reserved,
feedback-free final panel instead. This is a reporting clarification after the
frozen run, with no change to raw data, estimands or numerical analysis.

An evaluator-only diagnostic finds both true component features in the final
selected set for 11/32 shared novel reports; 23/32 reach the twelve-feature cap.
These facts suggest a second limitation beyond audit cost: irreversible early
feature choices can fill the small representation with spurious components.
The full 84 search ablation does not establish a cure. A diagnostic is not proof
that a particular replacement rule would fix the problem; no such repair has
been tuned on these evaluation streams.

The new proof layer is useful accounting, not a solution by itself. Lean states
how actual erroneous promotions and accumulated tolerances limit historical
finite-population value. The statistical sampling law, real-executor values and
probability bound remain separate obligations. Fixed report dispatch preserves
untouched installed functions, not arbitrary capabilities under learned routing
or distribution drift. The fixed half-bet's positive-mean power counterexample
further shows why a valid gate can be impractical even without a finite pair cap.

The next experiment should test learned schema facts and query fragments against
same-backbone legal-history and memory controls, with their complete cost paid.
It should follow each native benchmark's feedback rules and keep any gold-guided
admission experiment in a separately named track. The concrete mechanism,
resource cap, primary-source antecedents and kill criteria are in NEXT_STEP.md.
The monomial example is retained as a falsification test, not optimized further
as evidence that the general problem is solved.
