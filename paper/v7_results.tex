Matched old-report panels show 0 changed policy/prediction entries during novel learning. Those execution paths are unchanged by construction under fixed public dispatch. This supports the implementation invariant, not inferred task identity or arbitrary-distribution retention.

An evaluator-only diagnostic finds all true component monomials in the final selected features for 34.4\% of shared novel reports, while 71.9\% reach the twelve-feature cap. These hidden recipes are examined only after execution. Irreversible early feature additions can exhaust the cap with spurious choices; larger candidate search alone need not repair that failure. This is a diagnostic inference from the saved feature sets, not an additional confirmatory hypothesis.
