\begin{abstract}
We study deployment-time learning from interaction feedback without an intervening
offline retraining phase. An earlier evidence-preserving prototype failed when its
rule class was misspecified or the environment changed without a public version.
This revision supplies a schema-derived executable representation, correct replay
when its class grows, immutable skill archives with recurrence-weighted recovery,
and local admission tests using either real paired rollouts or one randomized
observed outcome. We prove conditional replay, recovery, noninterference, and
fixed-feature retention properties, while separating them from unrestricted
no-forgetting claims. An information bound explains why small diffuse gains cannot
generally be validated in a few episodes. A typed relational aggregate cube shares
execution work across skills. Across 20-seed CPU mechanism experiments, late reward
under hidden arithmetic change rises from 14.49\% to 96.19\%; recurrence-weighted
relational recovery reaches 97.45\%, versus 63.59\% for reset-only learning. An
integrated audited agent learns, but its audition cost lowers overall reward.
Rapid switches, noisy feedback, unsupported operators, and full-rank protection
remain explicit failures. The artifact contains 146 passing Python tests, 432
passing C++ cases, 29 unverified Lean theorem attempts, and uncompiled CUDA drafts.
No LLM or native public-benchmark superiority, GPU speedup, or novelty of the whole
combination is established.
\end{abstract}

\section{Problem, scope, and existing approaches}
An improving agent must turn earlier experience into better decisions on later,
non-identical episodes. An archive that never deletes data does not imply that
the agent selects the right evidence, preserves its meaning, or improves reward.
CL-Bench evaluates shared learnable structure across stateful task streams and
finds that dedicated memory mechanisms do not reliably dominate naive in-context
learning (ICL) in its evaluated settings \cite{clbench}. AgentCL further separates
compositional reuse from misleading learning curves \cite{agentcl}. Raw ICL must
therefore remain a primary experimental competitor, not a weak straw baseline.

Several substantial ingredients already exist. ACE maintains evolving playbooks
\cite{ace}; Voyager learns executable skills \cite{voyager}; EvoTest and TTHE
change the surrounding agent configuration or executable harness during testing
\cite{evotest,tthe}. ALMA searches executable memory designs \cite{alma}.
Decision-Aware Memory Cards select context by its estimated influence on actions
\cite{cards}. Selecting representative synthesis examples also predates this work
\cite{representative}. None of ``memory as code,'' ``decision-relevant evidence,''
or ``learning at test time'' is our novelty claim.

Safe policy improvement has its own strong literature. SPIBB constrains changes
using baseline bootstrapping \cite{spibb}; Deep SPI studies online improvement
with learned representations and world models \cite{deepspi}. Our local audit
uses real outcomes rather than assuming a learned model is a sound counterfactual
oracle. Its validity still needs appropriate sampling and frozen comparisons.
Sequential inference and off-policy evaluation already provide the relevant
statistical foundations \cite{confidence,offpolicy}. Our recurrence and projected
learning mechanisms similarly draw on tracking experts and orthogonal updates
\cite{tracking,auer,ogd}.

\paragraph{Research target.}
Can evidence-preserving executable learning improve the reward/cost/retention
frontier of real continual agents relative to strong, matched-budget ICL and
harness-adaptation systems? The broad benchmark question remains open here.
This revision resolves concrete implementation and mathematical defects in our
initial approach, tests a restricted integrated system, and specifies the
conditions under which the proposed mechanisms succeed or fail.

\paragraph{Assumptions.}
The exact-elimination branch receives an immutable public input, its own chosen
action, and truthful binary success. It sees no hidden regime ID or correct
answer after failure. A fixed epoch's recovery theorem assumes a deterministic
true rule in the current finite class. The live statistical branch assumes
randomized treatment before reward and no cross-episode treatment carryover;
it does not assume that unsuccessful actions reveal unchosen rewards. General
language understanding, noisy labels, and multistep interaction require separate
arguments. They are not solved by calling a generated candidate set complete.

A stored skill's identity never changes to reflect a new hypothesis.

The unaudited proposer is useful for diagnosing information reuse independently

not a label attached afterward to the proposer's higher scores. Soft expert
tracking and projected parameter learning are independently implemented controls;
they are not all integrated into one general-purpose LLM agent.

\subsection{Executable representations grounded in public structure}
The new relational intermediate representation consists of typed sum/difference
plans, nullable-Boolean filters, explicit column references, and schema guards.
Its grammar is generated from public column names and types. A strict JSON parser
also accepts model-proposed plans without executing ambient SQL or arbitrary code.
The reference interpreter and an independent read-only SQLite backend agree on
empty tables, negative values, and explicit NULL behavior in the executed tests.

A plan such as ``sum gross minus fee over completed, non-refunded rows, treating a
missing refund flag as zero'' transfers to new rows without memorizing their
answers. This solves a concrete representation problem left by the arithmetic
prototype. It is not a complete SQL language or a demonstrated natural-language
semantic parser. Schema guards validate dependencies and types, not business
meaning. Unsupported multiplication is deliberately tested and fails.

\subsection{A defect in fixed-class witness compression}
For a finite class $H$ and evidence $E$, define
\begin{equation}
 V(H,E)=\{h\in H:\forall e\in E,\ C_e(h)\},
\end{equation}
where $C_e(h)$ states that $h$'s prediction agrees with the observed success or
failure of the chosen action. Retain an observation as a witness only when it
shrinks the live set. For a fixed class, replaying the witnesses gives the same
set as replaying all evidence, including an empty result.

\begin{proposition}[Growth requires backfill]
For any classes $H,G$ and evidence $E$,
\begin{equation}
 V(H\cup G,E)=V(H,E)\cup V(G,E).
\end{equation}
A witness set sufficient for $H$ need not be sufficient for $H\cup G$.
\end{proposition}
\begin{proof}
The equality follows by distributing membership in $H\cup G$ over the common
constraint conjunction. For the counterexample, let $H$ contain only a constant
zero rule and observe a successful zero answer at $x=1$. The witness set is empty,
because nothing was eliminated. A newly proposed rule returning one at $x=1$
passes that empty witness set and fails the original observation.
\end{proof}

The implementation stages an enlarged class, replays the full current epoch's
raw evidence, reconstructs its witness set, and installs the result atomically.
It never backfills a new rule only against an old summary. Historical incompatible
epochs remain archived rather than being silently treated as stationary evidence.
The raw log grows; the active sufficient witness set is not constant total memory.

\subsection{Recovery without erasing old skills}
When evidence becomes contradictory, the learner first tries the next bounded
grammar tier. If full backfill remains inconsistent, it opens a new inference
epoch, preserving old programs. This is an internal evidence epoch, not an oracle
announcement of the environment's change point. It does not distinguish all cases
of drift from misspecification.

A fresh epoch uses prior
\begin{equation}
 \pi(h)=\frac{1-\beta}{|H|}
       +\frac{\beta}{|A|}\ind\{h\in A\},
\label{eq:archive}
\end{equation}
where $A$ is the archived subset; with an empty archive, use the uniform prior.
The implementation uses $\beta=4/5$. It predicts the maximum-mass action and
eliminates inconsistent rules after exact feedback. New ambiguous explanations
are marked empirical, not certified.

\begin{theorem}[Conditional recurrence recovery]
Within a fixed realizable deterministic epoch, if at most $K\ge2$ distinct actions
are predicted, the number $M$ of mistakes obeys
\begin{equation}
 M\le\frac{\log(1/\pi(h^*))}{-\log(1-1/K)}.
\label{eq:mistakes}
\end{equation}
For an archived truth under Eq.~\eqref{eq:archive}, the numerator is at most
$\log(|A|/\beta)$.
\end{theorem}
\begin{proof}
Every mistaken maximum-mass action is supported by at least $1/K$ of surviving
mass. Failure deletes all that mass. The true rule survives with its original
positive mass $\pi(h^*)$. Thus $\pi(h^*)\le(1-1/K)^M$; rearrange. The archive bound
uses $\pi(h^*)\ge\beta/|A|$.
\end{proof}

This is a weighted elimination argument, not a new general regret theorem.
If a fixed final class uniquely identified the old rule, its first incorrect
prediction after a hidden switch triggers contradiction. Earlier predictions
remain correct until the first disagreement. That conditional one-mistake
trigger does not cover noisy feedback, incomplete identification, rapid changes,
or new mixed-history rules introduced by grammar expansion.

\section{Admission that exploits locality}
A general small improvement can be difficult to recognize. The remedy is not to
use a looser significance threshold or recycle proposal data as validation. We
restrict a proposed replacement to a frozen region of behavior and distinguish
cheap screening from expensive fresh outcome collection.

\subsection{Pointwise protection outside a patch}
For pure one-step policies $b,c$ and an observable frozen gate $g$, let
\begin{equation}
 p(x)=\begin{cases}c(x)&g(x)=1,\\b(x)&g(x)=0.\end{cases}
\end{equation}
Outside the gate the complete action is unchanged. With common input/randomness,
$D=R(p)-R(b)=0$ there. Under stationary contexts,
\begin{equation}
 \EE D=\rho\,\EE[D\mid g=1],\qquad \rho=\PP(g=1).
\label{eq:local}
\end{equation}
Thus positive conditional mean benefit suffices when $\rho>0$.
Protected inputs outside the patch need no statistical test. Protected subgroups
inside it still need their own obligations or tests; an aggregate improvement
cannot guarantee every subgroup's retention.

For an arbitrary candidate, a one-step disagreement gate $g(x)=\ind[b(x)\ne c(x)]$
makes the patch behavior equal to $c$ everywhere. Evaluating that gate costs both
candidate predictions. It is not automatically cheap for LLMs. A syntactic
applicability gate can be cheaper but must still bind the actual deployed patch.

\subsection{Sequential evidence and honest rollout accounting}
For fresh paired differences $D_i\in[-1,1]$ and predictable stakes
$\lambda_i\in[0,1]$, define
\begin{equation}
 M_n=\prod_{i=1}^{n}(1+\lambda_i D_i).
\end{equation}
Under the null $\EE[D_i\mid\mathcal F_{i-1}]\le0$, each factor is nonnegative with
conditional mean at most one. Therefore $M_n$ is a nonnegative supermartingale.
Fixed mixtures preserve this property. The reference supplies fixed-stake tests
and an additional small-stake/predictable-variance variant. These are applications
of established anytime-valid inference \cite{confidence,offpolicy}.

Candidate $j$ receives $\delta_j=\delta/[j(j+1)]$ and is admitted when its mixture
crosses $1/\delta_j$. A conditional Ville bound followed by a union bound controls
ever accepting a null candidate by $\delta$. The indices must be globally unique;
candidates, guards, and comparators must be frozen before their audit data; an
obsolete comparator cannot authorize a current replacement. These assumptions
are operational requirements, not facts checked by a numerical threshold.

\begin{proposition}[Zero-skipping changes cost, not evidence]
Deleting observations whose true paired difference is zero leaves a fixed-stake
multiplicative audit path unchanged. It also leaves the supplied predictable
variant unchanged, since its statistics update only through $D_i,D_i^2$.
\end{proposition}
\begin{proof}
A zero difference contributes factor one and changes neither running statistic.
Induction over the omitted positions gives equality at every informative prefix.
\end{proof}

At $N$ deployment opportunities with $n_g$ gated cases, dense evaluation uses
$2N$ rollouts and screened evaluation uses $N+n_g$. The extra rollout count falls
from $N$ to $n_g$, approximately a $1/\rho$ factor. The \emph{total} rollout savings
are bounded by two in this accounting, and calendar waiting is unchanged. A modern
variance-adaptive test may already exploit the zeros statistically. We do not
claim that merely omitting them invents information or improves test power.

In a multistep environment, equality of the present action is insufficient. The
valid extension runs both frozen policy states on the common observed prefix,
then physically forks a simulator at the first behavioral divergence. Prefix
computation and both suffixes must be charged. This extension is derived but not
implemented in the present one-step harness.

\subsection{One observed reward instead of two hypothetical rewards}
When genuine paired forks are unavailable, independently randomize treatment
$A\sim\operatorname{Bernoulli}(e)$ before its outcome. For
$e\in[p_{\min},1-p_{\min}]$ and observed $R\in[0,1]$, use
\begin{equation}
 Z=\left(\frac{A}{e}-\frac{1-A}{1-e}\right)(R-1/2),
 \quad B=\frac{1}{2p_{\min}}.
\label{eq:randomized}
\end{equation}
Randomization implies $\EE Z=\EE R(c)-\EE R(b)$ and $|Z|\le B$.
The same test uses factors $1+\lambda_i Z_i/B$. At $e=1/2$, $B=1$.
The centered estimator is implemented with exact rational arithmetic and tested
by enumerating treatment probabilities and reward pairs.

The integrated system uses only the reward of the executed action. It freezes a
provisional candidate even before unique identification, because an uninformative
incumbent can otherwise prevent discovery forever. A candidate may be retired,
but its audit cannot omit unfavorable samples and resume. A replacement proposal
starts after its birth observation. Audit treatments can lower individual-episode
reward: safe admission is not safe exploration.

\subsection{An information limit on short auditions}
\begin{proposition}[A standard testing lower bound]
For iid $D\in\{-1,+1\}$ with null mean zero and alternative mean $\mu>0$, a test
with $0<a<1-b<1$, null admission probability at most $a$, and alternative power
at least $1-b$ satisfies, under finite-horizon or appropriate integrable stopping conditions,
\begin{equation}
 \EE_\mu N\ge
 \frac{\KL(1-b\Vert a)}{\KL((1+\mu)/2\Vert 1/2)}.
\label{eq:lower}
\end{equation}
\end{proposition}
\begin{proof}
The likelihood-ratio chain rule accumulates one Bernoulli relative entropy per
informative observation. Data processing to the final binary admission decision
lower-bounds this total by $\KL(1-b\Vert a)$. This is the usual change-of-measure
argument \cite{lowerbound}.
\end{proof}

At $a=.025$, $b=.2$, and $\mu=.05$, Eq.~\eqref{eq:lower} requires at least
$1963.79$ expected informative observations. A universally reliable 128-episode
test for a five-point high-variance gain is not supported by the information.
For a sparse patch with $\rho=.1$ and conditional gain $.5$, the same global
five-point gain has a lower bound of $18.77$ \emph{gated} observations. Waiting for
them still counts. The research opportunity is to construct useful low-variance
local changes, not to hide the unavoidable cost of diffuse ones.

\section{Retention with online parameter learning}
Freezing existing modules preserves their definitions, not correct selection.
For noisy or ambiguous feedback, hard deletion is inappropriate. We implement a
fixed-share EXP4-style routing control over an immutable finite archive
\cite{tracking,auer}. With action probabilities
$p_t=(1-\gamma)q_t+\gamma/K$, selected-action loss estimates are
\begin{equation}
 \widehat\ell_{t,i}=
 \frac{\ell_t(A_t)\ind[a_{t,i}=A_t]}{p_t(A_t)}.
\end{equation}
After exponential updating, a share $\alpha/M$ restores each expert's positive
weight. The standard potential analysis gives expected regret against an
$S$-switch expert sequence bounded by
\begin{equation}
 \frac{B_S}{\eta}+\frac{\eta KT}{2(1-\gamma)}+\gamma T,
\label{eq:tracking}
\end{equation}
where
\begin{align}
 B_S={}&\log M+S\log(M/\alpha)\nonumber\\
 &+(T-1-S)\log(1/(1-\alpha)).
\end{align}
This is an expectation bound for a fixed archive with nonanticipating losses,
not safe exploration, a growing-expert result, or regret against the different
state trajectory of a reactive environment. It can be vacuous for rapid changes.

For trainable residuals, freeze the feature extractor $\phi$ and prior prediction
$f$. Let $U$ have orthonormal columns spanning protected features and set
$P=I-UU^\top$. Define
\begin{equation}
 f_{\mathrm{new}}(x)=f(x)+WP\phi(x).
\label{eq:projection}
\end{equation}

\begin{theorem}[Exact fixed-feature protected span]
If $\phi(x)\in\operatorname{span}(U)$, then Eq.~\eqref{eq:projection} equals $f(x)$
for every $W$. For an approximate projection $\widetilde P$, drift is at most
$\|W\|\,\|\widetilde P\phi(x)\|$ in compatible norms.
\end{theorem}
\begin{proof}
Orthogonality gives $P\phi(x)=0$. For the approximate case, apply the operator-norm
inequality to $W\widetilde P\phi(x)$.
\end{proof}

This is fixed-feature nullspace control, related to orthogonal-gradient methods
\cite{ogd}, not a new neural retention theorem. It is exact in real arithmetic,
not merely first-order, because the new residual is explicitly linear in projected
features. The implementation uses float64 SVD and online SGD; measured drift,
rather than bitwise equality, is reported. Changing the encoder, feature
construction, router, or protected set changes the premise.

\begin{proposition}[The capacity cost is explicit]
For isotropic features and desired linear change $d^*$, the least achievable new
population squared error under this restriction is $\|U^\top d^*\|^2$.
If the protected span has full rank $d$, no residual learning is possible.
\end{proposition}
\begin{proof}
Decompose $d^*$ into its orthogonal protected-span and complement components.
Only the latter is adjustable. Isotropy makes squared prediction error equal to
the squared coefficient norm. At full rank, $P=0$.
\end{proof}

Observable context-separated features or new frozen modules can supply additional
capacity. An unobservable conflicting context cannot be resolved merely by
projecting gradients. Thus exact protected behavior and learning capacity must be
reported together.

\section{Execution: share semantics before optimizing kernels}
\subsection{A shared relational aggregate cube}
With $F$ nullable Boolean fields, each row belongs to exactly one of $3^F$
patterns. For $C$ numeric columns, form the integer cube
\begin{equation}
 A[z,c]=\sum_{r:\operatorname{pattern}(r)=z}\operatorname{coalesce}(r_c,0).
\end{equation}
Each typed filter is a fixed subset of patterns. Its column sums are linear
combinations of $A$, and a sum/difference plan selects one or two resulting
columns. Disjoint partitioning and distributivity prove equivalence to the direct
interpreter. The exact CPU implementation is tested against that interpreter,
which is independently checked against SQLite.

Direct evaluation costs $O(HR(F+1))$ for $H$ plans and $R$ rows. With $P_f$
distinct filter signatures, the cube costs
\begin{equation}
 O(R(F+C)+P_f3^F(F+C)+H).
\end{equation}
The cube itself uses $O(3^FC)$ storage; cached filter sums use $O(P_fC)$ and
materialized outputs use $O(H)$. This only helps for a small number
of flags. The reference caps $F$ at three and $C$ at eight and checks integer
magnitude bounds. Exponentially large cubes require fallback, not optimistic
extrapolation.

\subsection{Packed evidence and query-consensus kernels}
The CUDA draft assigns one warp to 32 hypotheses. Integer comparisons produce a
consistency ballot; bitwise intersection updates the live mask. Per-word active
counts and min/max predictions feed a second per-scope reduction. Nonempty equal
min/max values indicate empirical unanimity. An empty set never does.
New-input consensus has a separate entry point: the predictions computed for a
feedback observation cannot be reused as predictions for a future query.

The current fast path accepts int32 outputs, uint8 feedback, and uint32 masks.
General relational sums use int64 and need a checked range or a future int64
specialization. No silent truncation is allowed. NVIDIA's programming and tuning
guides inform the layout, not a claim of hardware speedup \cite{cuda,hopper}.
Tensor cores are unnecessary for this mask logic. A shared aggregate-cube GPU
implementation is an explicit next kernel, not an already executed result.

Buffers must bind owner, content epoch, schema, grammar, rule ordering, query,
evidence generation, precision and stream dependencies. Shape-only reuse is not
a valid content cache. Small classes should stay on the CPU when launch and
transfer costs dominate. Prediction generation, replay, screens, and archive
traffic belong in end-to-end accounting.

\section{Executed experiments}
\subsection{Protocol and implementation status}
We use 20 seeds per mechanism setting. Arithmetic experiments have 512 episodes
and three methods across seven scenarios. Relational experiments have 384
episodes and four methods across three scenarios. The integrated test has 512
episodes, two configurations and two scenarios. Together they produce
348,160 compressed per-episode records. Auditing simulations use 4,000 independent
replications per condition. The fixed-share and protected-training controls have
separate seeded result files. These are CPU mechanism tests, not CL-Bench,
AgentCL, or LLM scores.

The environment supplies public inputs and feedback for the learner's chosen
action only. Hidden arithmetic coefficients and evaluator recipes are never passed
to the learner. Relational test rows are newly generated each episode. Evaluation
recipes are coded independently of grammar enumeration, although the grammar and
in-grammar tasks are deliberately co-designed to test these mechanisms. That
restriction must not be confused with broad semantic generalization.

The repository currently passes 146 Python tests and 432 standalone C++ cases.
The 29 Lean declarations remain unverified because the toolchain is absent.
CUDA sources were neither compiled nor executed. Full raw histories and the
original v0.1 results are retained. Seed-level bootstrap intervals are included
in the arithmetic and relational result files; table means do not establish
public-benchmark significance.

\section{What would establish or kill the broader claim?}
The primary next experiment must use native stateful benchmark interfaces and
real frozen models. Compare raw ICL, an established memory/playbook method, an
executable harness method, and Witness-CL under equal observable feedback and
full accounting of proposal, audit, retrieval and training costs. Begin with
relational and codebase tasks but do not present those as coverage of forecasting,
opponent modeling, or arbitrary long-horizon control. Native CL-Bench and AgentCL
runs were not executed for this draft \cite{clbench,agentcl}.

Use unseen schema names and compositions, key and NULL changes, unsupported
operators, correlated failures, recurrence, and latent change without public
version labels. A strong parser and ICL baseline must not receive a smaller
context or fewer interactions than our system. Freeze implementations, budgets,
normalization, retention strata and seeds before scoring. Report seed-level
paired intervals and all negative settings. A five-point aggregate normalized
reward gain with no more than a one-point protected-stratum loss remains a
proposed success criterion, not a prediction or an achieved result.

The main contribution is killed if gains disappear under matched budgets or
stronger ICL, fail on unseen compositions, or hide protected-task regressions.
The admission mechanism is killed for a workload if useful gates occur too
rarely to amortize auditions. The kernel claim is killed if full prediction,
replay, synchronization and transfer cost exceeds saved computation. The
projected learner is inappropriate when the protected span removes all useful
capacity and observable context separation is unavailable.

\paragraph{Resources and safety.}
All executed experiments need only a CPU. A GH200 can host the next local-model
and CUDA validation stage, subject to measured model/context memory requirements;
no GPU-hour estimate is justified before a pilot. The supplied CUDA target
includes compilation and sanitizer commands, not successful results. No model
service calls, API spending, external dataset submission, repository publication,
or irreversible actions were performed. A real agent needs an independent
permission boundary and authenticated feedback. Mean-reward admission is not an
irreversible-action safety certificate.

\section{Conclusion}
This revision replaces three unimplemented design questions with executable,
falsifiable mechanisms: schema-grounded skill growth with honest replay,
recurrence-aware archival recovery, and local admission with actual outcomes.
It also supplies an explicit online protected-learning construction and shared
execution primitive. The improvement is substantive within the tested setting,
but the outcome is not a general no-forgetting learner or a demonstrated public-
benchmark winner. The restricted proofs, failures, and measured admission cost
specify exactly what a larger experiment must validate.

\section{Additional proof and implementation details}
\subsection{Fixed-class witness equivalence}
Let $V_0=H$ and $V_t=V_{t-1}\cap C_t$. If a constraint does not shrink $V_{t-1}$,
it holds for every later subset. Induction therefore permits its omission without
changing the final version space. Every retained witness removes at least one
previously surviving hypothesis, so $|W_t|\le |H|-|V_t|$. This is not a minimum
cardinality witness construction. The bound counts observations, not their bits.
The class-growth counterexample in Section~2 explains why this sufficiency
contract must name its class explicitly.

\subsection{Sketch of the fixed-share expectation bound}
Interpret sharing as a Markov prior over expert paths. The probability of an
$S$-switch comparator is at least
$M^{-1}(\alpha/M)^S(1-\alpha)^{T-1-S}$, giving code length $B_S$.
The exponential-weights potential uses $e^{-z}\le1-z+z^2/2$ for $z\ge0$ and
$\log(1+u)\le u$. It bounds estimated regret by the code length over $\eta$ plus
$\eta/2$ times the summed estimated second moments. Conditional expectation of
a round's second moment is
\begin{equation}
 \sum_a\frac{q_t(a)\ell_t(a)^2}{p_t(a)}\le\frac{K}{1-\gamma}.
\end{equation}
Comparator IPS estimates are unbiased. Mixing exploration adds at most $\gamma$
loss per round. These steps give Eq.~\eqref{eq:tracking}. None compares against
an expert's counterfactual environment trajectory after different earlier actions.

\subsection{Randomization and the audit filtration}
The candidate and baseline functions, guard and reward normalization are fixed
before their test data. Within a gated episode, assignment is independent of
potential outcomes conditional on the preassignment information. Hence
\begin{align}
 \EE\!\left[\frac{A}{e}(R-1/2)\right]&=\EE[R(c)]-1/2,\\
 \EE\!\left[\frac{1-A}{1-e}(R-1/2)\right]&=\EE[R(b)]-1/2.
\end{align}
Subtracting yields Eq.~\eqref{eq:randomized}. The uniform bound $B$ is deliberately
constant. Using context-dependent normalizers can change the targeted average.
After hidden drift, stationary interpretation is not automatic; a detected
evidence-epoch change retires the ongoing test, but detection itself can lag.

An audit stopped for a contradicted candidate is never resumed. Admissions remain
a subset of crossings of its full, uncensored potential test path. A newly proposed
candidate excludes the observation that produced it via its strict birth cut.
Unlimited restarts without new global error indices would invalidate the claim.
The reference allocator is single-process; durable distributed indexing is not
implemented.

\subsection{Formalization and execution boundaries}
\texttt{Core.lean} contains 13 earlier theorem attempts. The 16 additions in
\texttt{Refinement.lean} cover replay under class growth, its explicit
counterexample, guarded patch noninterference, immutable archive outputs, an
integer residual identity, and neutral-factor algebra. They use no placeholders
or added axioms, but \texttt{lake build} did not execute because \texttt{lake}
is unavailable. There is no kernel-checked Lean result to cite.

Probability, real matrix algebra, the sample lower bound, and compiler refinement
remain handwritten arguments. Python and C++ test results do not prove the CUDA
program. The C++ oracle has 432 random/tail/idempotence cases. The unexecuted CUDA
runner adds empty-mask and extreme-int sentinel cases. Multistream, graph replay,
changing-content and buffer-reuse validation are still required before production.
